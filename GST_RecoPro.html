How it works

  1. Normalise. GSTIN: upper-case, symbols removed. Invoice no.: upper-case; symbols removed; leading zeros in numeric parts ignored (so INV/001 = INV-1). Dates: dd/mm/yyyy, dd-mm-yyyy, yyyy-mm-dd, dd-Mon-yyyy and Excel serials. Amounts: ₹, commas and (brackets) handled.
  2. Exact pass. Same GSTIN + same normalised invoice no. Status Matched if taxable value and each tax head are within the amount tolerance and the date is within the date window; otherwise Mismatch with the reason listed.
  3. Fuzzy pass (optional). Same GSTIN with a similar invoice no. (Levenshtein similarity ≥ threshold, or ≥ 50% with equal value and date), plus same invoice no. under a different GSTIN with equal value. These are Probable and need your review.
  4. One-to-one pairing. All candidate pairs are ranked (exact first, then confidence) and assigned greedily, so no invoice is paired twice or counted twice.
  5. Leftovers. Repeated GSTIN + invoice keys are Duplicate; the rest are Missing in 2B or Missing in PR. Rows with no GSTIN or invoice number stay visible as missing. Nothing is dropped except fully blank rows (counted and reported). An integrity check confirms every row is accounted for.
  6. Confidence = 50% invoice similarity + 30% taxable-value closeness + 20% date closeness.

Verification warnings

  • Discrepancies are review flags, not ITC disallowances. Eligibility depends on the CGST/IGST Acts, rules, notifications and facts of each case; this tool assesses none of that.
  • Credit/debit notes, RCM, ISD, import and amendment records are not treated specially; reconcile them as separate files or with signed values and review manually.
  • GSTIN checks are format-only (no checksum or portal lookup). Confirm the GSTR-2B period matches your books period.

Using the file

  • Needs SheetJS for Excel files. It loads from cdnjs when online; for fully offline use, save xlsx.full.min.js (SheetJS 0.18.5) next to this HTML file and it is picked up automatically. CSV import works without it; Excel export falls back to CSV.
  • Large files: matching is indexed by GSTIN, so tens of thousands of rows are fine in a modern browser.
